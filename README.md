# Лист приключений — D&D

Помощник для очных партий D&D 3.5, 5e 2014 и 5e 2024.

## Возможности

- Листы персонажей, здоровье, временные хиты, навыки и спасброски.
- Заклинания, ячейки, концентрация и классовые ресурсы.
- Инвентарь с местами хранения, количеством и весом.
- Кубики, смешанные формулы, пресеты и анимированное поле броска.
- Автоматический учёт заданных модификаторов, экипировки и активных эффектов.
- Русский, English и двуязычные игровые названия.
- RGB-темы, градиенты, стекло, оформление кубиков и заметки.

## Запуск GitHub Pages

1. Откройте Settings → Pages.
2. В Source выберите Deploy from a branch.
3. Выберите ветку main и папку /docs, затем Save.
4. После публикации адрес сайта появится на той же странице.

Для приватных репозиториев доступность Pages зависит от тарифа GitHub. Видимость репозитория этот проект не меняет.

## Локальный просмотр

Из корня репозитория: `python -m http.server 8000 --directory docs`, затем откройте http://localhost:8000.

## Проверка

Node.js 20 или новее: `npm test`. Внешние npm-зависимости не требуются.

## Состояние прототипа

Данные хранятся в браузере. Персонажи со старого адреса автоматически на новый адрес не переносятся. Полная автоматизация правил, синхронизация аккаунтов и оплата пока не реализованы. Сочетание эффектов и допустимость бонусов определяет мастер. Анимация кубиков стилизованная двумерная, без 3D-физики.

GitHub Pages предназначен для демонстрации прототипа; коммерческий сервис с платежами следует размещать на подходящем отдельном хостинге.
